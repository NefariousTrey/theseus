# orderflow (Theseus demo target)

A tiny order pricing pipeline, written for the Theseus demo. Each file in
`lib/steps` is a plugin that runs on every order. Two of them are leftovers from
older versions: they run, but nothing uses their results. One file is never
loaded at all. Run Theseus on it and see which is which.
